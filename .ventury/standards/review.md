# Padrão para revisão

A revisão deve verificar:

- aderência à especificação e ao contexto do projeto;
- preservação dos contratos existentes;
- ausência de mudanças desnecessárias;
- tratamento de erros e riscos relevantes;
- cobertura do novo comportamento por testes;
- resultado das validações configuradas no manifesto;
- ausência de dados sensíveis, código temporário ou controles removidos.

Problemas devem ser descritos com impacto, evidência e correção esperada.
