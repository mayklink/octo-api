# Padrão para pull requests

Uma pull request deve:

- explicar o objetivo e o escopo da mudança;
- relacionar a especificação atendida;
- listar as alterações relevantes;
- informar as validações executadas e seus resultados;
- registrar riscos, limitações e decisões tomadas;
- evitar mudanças não relacionadas à tarefa.

Falhas conhecidas, validações não executadas e incompatibilidades devem ser declaradas explicitamente.
